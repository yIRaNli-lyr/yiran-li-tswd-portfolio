# Yiran Li — Telling Stories with Data

## About me

Hi! My name is Yiran Li. I am a master's student in the MISM program at Carnegie Mellon University. I am interested in data across both backend engineering and frontend development.

## What I hope to learn

In this course, I hope to learn how to make complex data easier for people to understand. My goals are to:

1. Use charts and visual evidence to tell clear stories and support conclusions.
2. Turn complex technical information into accessible visual explanations.
3. Apply design principles that help readers identify key insights quickly.
4. Build a portfolio that demonstrates the full process from analysis to presentation.
